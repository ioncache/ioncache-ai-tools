# Privacy

Identify actual personal-data flows and their documented purposes before
judging collection, processing or disclosure. Do not invent legal obligations,
regulated data, retention periods or consent requirements.

Check whether collected fields, derived data, logs, analytics, exports and
copies are necessary for the supported purpose and reach only the intended
recipients. Follow retention/deletion obligations through caches, durable
storage, backups and downstream consumers when those obligations apply.

Verify that documented user controls and processing restrictions reach the
actual data flow. Establish a concrete disclosure, excessive processing or
unfulfilled obligation; missing purpose documentation is uncertainty, not proof
that processing is unlawful.
